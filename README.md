# DAA

Lab programs for 24-813-0505: Design and Analysis of Algorithms (CUSAT).

- Sorting: heap sort, insertion sort, merge sort, quick sort
- Trees: binary tree, BST, inorder / preorder / postorder traversal
- Graphs: BFS, DFS, Kruskal, Prim, Bellman-Ford, Dijkstra, Floyd-Warshall

Compile any file with `g++ file.cpp -o file` and run it.
